# Обновления / Updates

Выберите **Справка → Проверить обновления**. Проверка выполняется только по
команде пользователя через публичный GitHub API, без токена, входа и телеметрии.
Поддерживается переносимая Windows x64 сборка. Источник:
https://github.com/evdokimov1996/rmaa-plus/releases/latest

При новой стабильной версии приложение предлагает скачать архив и отдельно
подтвердить установку с перезапуском. Во время измерения обновление не начинается.
Сравнение версий числовое; prerelease не устанавливаются автоматически.

Проверяется размер и SHA-256 из GitHub Releases API, затем опись каждого файла
в bundle.json. Проверка целостности не является Authenticode-подписью.
Репозиторий GitHub остаётся доверенным источником обновлений: доступ владельца
к выпуску даёт возможность выпускать код программы.

Установщик запускается из временной распакованной сборки и ждёт закрытия
основного процесса. Файлы программы сохраняются в журнал отката до замены.
Новая версия проходит проверку запуска Tk/Matplotlib и совпадения версии.
При ошибке восстанавливаются прежние файлы; при успешном запуске временные
архивы, распакованная копия и откат удаляются. Нет постоянного фонового процесса.

Папка **data** и посторонние файлы не заменяются. Текущий результат перед
перезапуском сохраняется локально в **data/update-recovery-*.json** (при
непереносимом профиле — рядом с preferences.json). Не запускайте вторую копию
RMAA+ во время установки: Windows может удерживать файлы программы.

Отмена загрузки удаляет её временные файлы. Сетевая ошибка сохраняет текущую
версию и настройки. Нужен свободный диск для распаковки и временного отката.

## Восстановление после аварийного выключения

Сначала закройте все экземпляры RMAA+. Сохраните каталог
`%LOCALAPPDATA%/RMAAOpenLab/updates/<идентификатор>/`: в нём находятся plan.json,
bundle/ и rollback/journal.json. Не удаляйте его до восстановления.

Запустите **bundle/RMAA+.exe --recover-update "полный путь к plan.json"**.
Помощник восстановит прежние файлы по журналу, проверяя контрольные суммы
копий. Данные пользователя не входят в опись обновления. Затем запустите
обычный RMAA+.exe. При повреждении диска/копий используйте предыдущий выпуск
со страницы Releases, сохранив свою папку data. Физическое отключение питания
во время записи и повреждение носителя не могут быть исключены программой.

## Ручная установка

Распакуйте ZIP последнего выпуска в новую папку, перенесите свою папку data.
Сохраняйте весь каталог, включая _internal и portable.flag. Не заменяйте только EXE.

## Для разработчиков

Сборка: `python tools/build_release.py` на Windows с MSVC/CMake. GitHub Actions
проверяет тесты; тег **vX.Y.Z**, совпадающий с rmaa_version.py, собирает и публикует
выпуск. Сначала загружаются draft assets, затем независимый GET сверяет digest
каждого файла, и лишь после этого выпуск публикуется как latest. Имена assets
не переиспользуются: исправление выпуска требует новой версии.

The same workflow is available in English inside the application's F1 guide.
