# RMAA+ / RMAA Open Lab

Открытый независимый Windows x64 аудиоанализатор под GPL-3.0-or-later.
Проект не связан с RightMark и не содержит исходников, EXE или ресурсов оригинальной RMAA.

**[Скачать готовую Windows x64 версию](https://github.com/evdokimov1996/rmaa-plus/releases/latest)** ·
[Исходный код](https://github.com/evdokimov1996/rmaa-plus) · [Сборка](BUILD.md) · [Обновления](UPDATES.md)

Полная пошаговая инструкция встроена в программу: **F1** или **Справка → Как пользоваться**.
Доступны русская и английская версии; интернет для инструкции не нужен.
Для проверки обновлений выберите **Справка → Проверить обновления**. Установка
проверяет SHA-256, сохраняет данные и перезапускает приложение. Фонового опроса нет.

Готовая сборка не требует Python. EXE не подписан Authenticode; контрольные суммы
и точный source commit опубликованы с каждым выпуском. Не отключайте защиту
системы ради установки. Для самостоятельной сборки см. BUILD.md.

Распакуйте папку RMAA+ целиком и запустите RMAA+.exe.
Выберите вход/выход одного host API, Fs, формат и физические каналы. Для
одного подключённого входа выберите «Моно (вход 1)» или одинаковые номера
входов в Настройках. В моно нет вымышленных stereo balance/crosstalk.
Основной генератор: 0 dBFS peak, без регулятора цифрового ослабления.
Настройте аналоговый входной уровень по индикатору; клиппинг входа недопустим. Ping реально открывает/закрывает режим.

Выберите измерения и запустите тест. Флажок raw WAV сохраняет запись и
manifest до анализа; требуется новое имя .wav и свободное имя .json.
«Стоп» освобождает потоки сеанса. Настройки сохраняются локально при действиях
пользователя. RU / EN выбирает язык следующего запуска, включая отчёты.

Основной тест и экспорт WAV используют точный профиль: АЧХ с сеткой 1 Гц,
две фазовые реализации по 8 периодов, участки шума/тона/DR/IMD по 6 секунд,
64 точки CCIF по частоте. Полный моно-тест занимает около 2 минут плюс анализ.
Для длинных сеансов действует лимит 20 млн кадров: при высоких Fs выберите
меньше тестов или Fs 96 кГц / ниже. Это явный лимит памяти, не скрытое
сокращение теста. Старые manifest/JSON сохраняют прежнюю методику.

Автономный режим: экспорт WAV + manifest, внешнее воспроизведение/запись и
импорт соответствующей записи. В акустике есть detailed/thorough/subwoofer,
CSV относительной коррекции микрофона и THD(freq/level); SPL не определяется.

Перед тестом кнопка «Онлайн АЧХ / уровень» открывает отдельный монитор.
Нажмите «Запустить»: multitone 0 dBFS peak, RMS/Peak, пик и клиппинг,
относительная АЧХ к 1 кГц. Остановите монитор перед полным тестом.
Обновления и аудиопотоки существуют только во время активного мониторинга.

Результаты: техническое окно с перечнем тестов слева, большим графиком,
числами под ним и вкладкой гармоник. Нажмите на кривую для отсчёта
ближайшей сохранённой точки. Zoom/pan, ручные пределы осей, PNG,
выбор записей и L/R, 8 слотов, сравнение,
HTML/TXT. HTML содержит печать/PDF через браузер. SAV6.4.5 F9 имеет
двусторонний обмен числами и всеми девятью типами графиков, проверенный в
оригинале. Дополнительные собственные данные сохраняйте в JSON.
Собственная информационная шкала Open Lab описана в QUALITY.md.

У АЧХ шаг вертикальной сетки по умолчанию 0,5 дБ. Кнопки ±0,5 / ±1 / ±2 / ±3
меняют диапазон; отдельное поле задаёт шаг сетки (пустое = авто). Ручные
пределы применяются кнопкой или Enter; десятичная запятая поддерживается.
Y min должен быть меньше Y max; ошибка остаётся видимой до исправления.

Аппаратно проверяется Realtek → Cosmos mono/channel1, 48 kHz, WASAPI
Exclusive PCM32; живой монитор также PCM24. Это не аттестация иных драйверов, стерео или закрытых
алгоритмов оригинала. Старые версии и оригинальная RMAA не удаляются.

Портативная сборка: запускайте RMAA+.exe из папки RMAA+.
Файл portable.flag включает хранение настроек в data/preferences.json рядом
с EXE. Переносите всю папку вместе с _internal и data; установщик и Python
не требуются. На другом компьютере выберите доступные там аудиоустройства.
Папка должна быть доступна для записи. Результаты сохраняются в выбранное
пользователем место. Чистый ZIP не содержит личных настроек или измерений.

С версии6.2 тишина для шума и пилот −60 dBFS для динамического диапазона
остаются отдельными методическими сигналами. В акустическом THD от уровня
ступени доходят до 0 dBFS. Peak и RMS не равны: RMS чистого синуса с пиком
0 dBFS составляет −3.0103 dBFS. Приложение не меняет громкость Windows
или аналоговый gain. Старые манифесты/измерения со сниженным уровнем читаются.

С версии6.2.1 автоматический диапазон АЧХ не уже −0.5..+0.5 dB;
при больших отклонениях расширяется. Правило действует в результатах,
сравнении, HTML и акустической АЧХ. Ручной zoom остаётся доступен.
